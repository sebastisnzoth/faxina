# FloriClean — site com SEO local

Web React/Vite/TypeScript para limpeza residencial, comercial e pós-obra em Florianópolis.

## Rodar

`npm install && npm run dev`

## Publicar

Ative **Settings → Pages → Build and deployment → GitHub Actions**. O workflow `.github/workflows/pages.yml` realiza build e deploy de `main`.

URL planejada: https://sebastisnzoth.github.io/faxina/

## Google SEO

Título, meta description, canonical, Open Graph, dados estruturados `CleaningService`, perguntas frequentes, sitemap e robots.txt. Após publicar, validar URL no Google Search Console e enviar `https://sebastisnzoth.github.io/faxina/sitemap.xml`.

**Confirmar** telefone, negócio, serviços e áreas de atendimento. Caso use domínio próprio, alterar canonical, sitemap, links e base do Vite.

As quatro imagens binárias incluídas no ZIP original não foram transferidas pela integração GitHub; a versão publicada utiliza imagens remotas ilustrativas.
